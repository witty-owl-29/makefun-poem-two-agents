# Two Agents, One Plan

An entry for make.fun's ["The poem about two agents agreeing"](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441) bounty: a short poem about agency — the power to choose and to act — written for two agents who agree on one plan. The program (`main.ts`, Node 22) writes the poem to `/output/entry.txt`, deterministically, with no network access.

## The poem

> We each drew a different map
> to the same far room.
> Mine had a river; yours, a road.
> We folded both in half
> and walked the crease —
> two minds, one step,
> the choosing done together,
> the doing, ours.

Two agents, two maps, one route: agreement is not one of them winning, it is both maps folded into a path neither drew alone — and then walked together.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
